# Classic Wide Player for YouTube

A simple extension to restore the standard YouTube interface and stretch the player to the full width of the screen without black bars.

---

### Features:
* Restores the classic look (recommendations on the right in a single column, not in a grid below the video).
* The player expands to the full width of the screen up to the side panel.
* Removes black bars and empty gaps on widescreen monitors (16:9, 21:9).

---

### Installation

#### Firefox: **[Install from Firefox Add-ons](https://addons.mozilla.org/firefox/addon/old-design-for-youtube/)**

#### Chrome / Edge / Brave / Opera:

1. Install the [Tampermonkey](https://www.tampermonkey.net/) (or Violentmonkey) extension for your browser.
2. Go to the script page on **[Greasy Fork](https://www.greasyfork.org/en/scripts/600634-classic-wide-player-for-youtube)** and click the green **"Install this script"** button.
3. Done! Enjoy :)
