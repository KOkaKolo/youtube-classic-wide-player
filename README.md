# Classic Wide Player for YouTube

Простое и легковесное расширение для возврата нормального двухколоночного интерфейса YouTube и растягивания плеера на всю ширину экрана без черных полей.

A lightweight extension that restores the classic 2-column YouTube layout and expands the player to full width.

---

### Что делает / Features:
* Возвращает классический вид (рекомендации справа, а не в сетке под видео).
* Плеер раздувается на всю ширину экрана до боковой панели.
* Убирает черные поля и пустые дыры на широкоформатных мониторах.
* Не ломает сетку на Главной странице и вкладках каналов.
* 0 трекеров, чистый CSS и ванильный JavaScript.

---

### Установка в Chrome / Яндекс / Edge / Brave / Opera

1. Перейди в раздел **[Releases](../../releases)** справа и скачай архив `youtube-classic-wide.zip`.
2. Распакуй скачанный архив в любую папку на компьютере (например, в «Документы»).
3. В браузере перейди по ссылке:
   * В Chrome / Яндексе: `chrome://extensions/`
   * В Edge: `edge://extensions/`
   * В Opera: `opera://extensions/`
4. В правом верхнем углу включи тумблер **«Режим разработчика»** (Developer mode).
5. Нажми кнопку **«Загрузить распакованное»** (Load unpacked) слева вверху и укажи распакованную папку.
6. Готово! Открывай YouTube и пользуйся.
